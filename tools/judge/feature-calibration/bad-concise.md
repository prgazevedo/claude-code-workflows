## Context

The export button saves notes as JSON only. Users asked for CSV. To restate: today the only export format is JSON, and users have requested CSV as a format. In other words, CSV is not currently offered, only JSON is offered.

## Goal

The export button offers CSV next to JSON. Put differently, users can choose CSV where today they can only choose JSON.

## Acceptance Criteria

- A CSV choice appears next to the JSON one.
- The CSV has one row per note with title, date, and body columns.

## Scope: out

- Other formats. The existing JSON export path is unchanged.
